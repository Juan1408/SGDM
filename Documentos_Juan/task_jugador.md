# 📋 Tareas de Ejecución - Módulo Jugador

*Este módulo está destinado a los usuarios con Rol 3. Su enfoque es la experiencia del competidor: perfil, equipos y participación en torneos.*

- [ ] **0. 🚨 RECORDATORIO OBLIGATORIO: HACER `git pull` ANTES DE EMPEZAR A PROGRAMAR**

## 1. Dashboard del Jugador (`vistas/jugador/dashboard.php`)
- [ ] Maquetar la interfaz principal (cascarón) específica para el jugador.
- [ ] Mostrar métricas personales: Win/Loss ratio, Próximos Partidos, Torneos Activos.
- [ ] Menú lateral exclusivo (Mi Perfil, Mis Equipos, Buscar Torneos).

## 2. Perfil Deportivo
- [ ] Interfaz para que el jugador edite sus datos públicos (Alias/Nickname, Biografía).
- [ ] Sección para vincular sus cuentas de juego (Ej: Riot ID para Valorant/LoL, PSN ID, etc).

## 3. Gestión de Equipos (Roster)
- [ ] Pantalla para **Crear un Equipo** (El jugador que lo crea se convierte en el Capitán).
- [ ] Sistema de invitaciones:
  - Buscar otros jugadores registrados por Nickname/Email.
  - Enviar solicitud de unión al equipo.
- [ ] Bandeja de notificaciones: Aceptar o rechazar invitaciones a equipos de otros capitanes.
- [ ] Pantalla de "Mi Equipo" mostrando a todos los miembros actuales.

## 4. Participación en Torneos
- [ ] Explorador de Torneos: Lista de torneos en estado "Inscripciones Abiertas".
- [ ] Botón para Inscribirse (Si es un torneo individual, se inscribe solo; si es de equipo, lo inscribe el Capitán).
- [ ] Estado de la inscripción (Pendiente de aprobación por el organizador, Aprobado, Rechazado).

## 5. Historial y Calendario
- [ ] Calendario o lista de **Próximos Partidos** (Saber contra quién y a qué hora juegan).
- [ ] Historial de resultados pasados.
